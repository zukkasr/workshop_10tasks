# Практикум по адаптивной вёрстке

Откройте `index.html` в браузере и редакторе кода. Для работы достаточно браузера и любого текстового редактора.

- **index.html** — условия заданий, готовая разметка для заданий 01–05 и места для своей разметки в заданиях 06–10.
- **student.css** — файл для ваших стилей. Для каждого задания в нём есть свой раздел.
- **lab.css** — оформление практикума. Оставьте этот файл как есть.
- **mountains.svg** — местная иллюстрация для заданий с изображением.

После каждого изменения сохраните файл и обновите страницу. В режиме устройства в инструментах разработчика задавайте ширину и высоту области просмотра по условиям задания. Для проверки медиазапросов попробуйте ширину на один пиксель меньше порога и ровно на пороге.
